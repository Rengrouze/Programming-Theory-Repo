## 🕹️ Play the Game

You can play the game right here—no need to clone or download the repo!  
[Play on Unity Play](https://play.unity.com/en/games/e1541874-7a07-449d-866e-a06cf460ff2f/build)

- Created for fun and to learn the Unity engine
- Practice and demonstrate Object-Oriented Programming (OOP) principles: Encapsulation, Inheritance, Polymorphism, Abstraction
- Explore basic game design

## 🛠️ Technologies

- Unity Engine
- C#
